# Прогнозирование механических свойств композиционных материалов с помощью машинного обучения

## 🎯 Описание проекта

Дипломный проект, посвящённый разработке моделей машинного обучения для прогнозирования **модуля упругости при растяжении** композиционных материалов на основе их химического состава и параметров производства.

### 💼 Бизнес-ценность

Традиционное определение механических свойств композитов требует дорогостоящих и длительных физических испытаний образцов. Разработанная модель позволяет:
- **Сократить время** на получение данных о свойствах материала с дней до секунд
- **Снизить затраты** на лабораторные испытания
- **Оптимизировать состав** материала на этапе проектирования
- **Предсказывать свойства** новых композиций без их физического производства

## 📈 Описание данных

**Датасет:** ~1000 записей о композиционных материалах с 13 признаками

### Признаки:
| Признак | Описание | Тип |
|---------|----------|-----|
| Соотношение матрица-наполнитель | Пропорция компонентов | float |

| Модуль упругости, ГПа | Модуль упругости матрицы | float |

| Содержание эпоксидных групп, % | Химический состав | float |

| Поверхностная плотность, г/м² | Плотность наполнителя | float |

### Целевая переменная:
- **Модуль упругости при растяжении, ГПа** (среднее значение: ~73.3 ГПа)

## 🔬 Методология

### 1. Разведочный анализ данных (EDA)
- Анализ распределений признаков (boxplot, histogram)
- Корреляционный анализ с использованием матрицы **Phik** для выявления нелинейных зависимостей
- Выявление и визуализация выбросов

### 2. Предобработка данных
- **Обработка выбросов:** метод межквартильного размаха (IQR) — удалено 91 аномальная запись
- **Масштабирование:** StandardScaler для алгоритмов, чувствительных к масштабу (KNN, SVR)
- **Разделение данных:** train/test split (70/30)

### 3. Моделирование

Протестированы следующие алгоритмы регрессии:

#### ⚙️ Support Vector Regression (SVR)
- Метод опорных векторов для регрессии
- Подбор параметров: `C`, `kernel`, `gamma`, `epsilon`
- **Лучший результат среди классических методов**

#### 🌲 Random Forest
- Ансамбль деревьев решений
- Подбор гиперпараметров: `max_depth`, `max_features`, `min_samples_leaf`
- GridSearchCV с кросс-валидацией

#### 🎯 K-Nearest Neighbors (KNN)
- Метод ближайших соседей
- Оптимизация количества соседей `k`
- Требует масштабирования признаков

#### 🚀 CatBoost
- Градиентный бустинг на деревьях решений
- Автоматическая обработка категориальных признаков

#### 🧠 Нейронная сеть (TensorFlow/Keras)
- Архитектура: 2 скрытых слоя по 64 нейрона с активацией ReLU
- Оптимизатор: Adam
- Функция потерь: MSE
- Кросс-валидация с K фолдами

### 4. Оценка моделей

Метрики качества:
- **MAE** (Mean Absolute Error) — средняя абсолютная ошибка
- **MSE** (Mean Squared Error) — среднеквадратичная ошибка
- **RMSE** (Root Mean Squared Error) — корень из MSE

## 🏆 Результаты

### Сравнение моделей (Модуль упругости при растяжении)

| Модель | MAE | MSE | RMSE | Относительная ошибка |
|--------|-----|-----|------|---------------------|
| **SVR (GridSearch)** | **2.39** | **8.56** | **2.92** | **~3.98%** ✅ |
| Random Forest | 2.44 | 8.69 | 2.95 | ~4.02% |
| Нейронная сеть | 2.39 | 9.01 | 3.00 | ~4.09% |
| CatBoost | 2.52 | 9.24 | 3.04 | ~4.15% |
| KNN | 2.56 | 10.30 | 3.21 | ~4.38% |
| Decision Tree | 2.90 | 12.80 | 3.58 | ~4.88% |

### 🎯 Лучшая модель: **SVR с подбором гиперпараметров**

- **MAE: 2.39 ГПа**
- **RMSE: 2.92 ГПа**
- **Относительная ошибка: < 4%** при среднем значении целевой переменной ~73.3 ГПа

### Ключевые выводы:
1. SVR показал наилучшие результаты благодаря способности улавливать нелинейные зависимости
2. Нейронная сеть показала сопоставимые результаты, но требует больше вычислительных ресурсов
3. Все модели продемонстрировали относительную ошибку менее 5%, что делает их пригодными для практического использования
4. Корреляционный анализ выявил слабые линейные зависимости, что подтверждает необходимость использования нелинейных моделей
